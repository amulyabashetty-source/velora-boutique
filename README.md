# Velora Boutique 👗

Velora Boutique is a full-stack fashion e-commerce web application focused on traditional Indian outfits like sarees, lehengas, and kurti sets.

## 🚀 Features

- User authentication (Login / Signup)
- Product browsing by category
- Add to cart functionality
- Admin panel to add products
- Image upload using Multer & Cloudinary

## 🛠 Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB

## 📁 Project Structure

/client → React frontend  
/server → Node.js backend  

## ▶️ How to Run

### Frontend

cd client
npm install
npm run dev


### Backend

cd server
npm install
npm start
